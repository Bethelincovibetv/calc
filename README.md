# Elegant Calculator Web App

A simple yet visually stunning calculator web application designed with a focus on clean aesthetics, responsive layout, and intuitive interactions. It provides a familiar interface for performing basic arithmetic operations.

## Features

-   **Modern & Clean Design:** Inspired by world-class UI/UX principles (Stripe, Linear, Apple) with a minimalist aesthetic, high contrast, and pleasant typography.
-   **Responsive Layout:** Adapts seamlessly to various screen sizes, from mobile devices to large desktops, ensuring a consistent user experience.
-   **Basic Arithmetic Operations:** Supports addition (+), subtraction (−), multiplication (×), and division (÷).
-   **Clear & Delete Functionality:** `C` to clear all input, `DEL` to remove the last digit.
-   **Decimal Support:** Handles decimal numbers for precise calculations.
-   **Error Handling:** Displays 'Error' for invalid operations like division by zero.
-   **Keyboard Support:** Fully operable using your keyboard for numbers, operators, Enter/Equals, Backspace, and Escape/C for clear.
-   **Dark Mode Support:** Automatically adjusts to the user's system dark/light mode preference.

## Technologies Used

-   **HTML5:** For the semantic structure of the application.
-   **CSS3:** For styling, including Flexbox, Grid, custom properties for themes, and media queries for responsiveness.
-   **JavaScript (ES6+):** For all interactive logic and calculator functionality.
-   **Inter Font:** A modern, highly readable typeface for a premium feel (via Google Fonts CDN).

## How to Run Locally

To run this project on your local machine, follow these steps:

1.  **Clone the repository (or download the files):**
    If you're using Git, open your terminal or command prompt and run:
    ```bash
    git clone <repository-url>
    cd elegant-calculator
    ```
    (Replace `<repository-url>` with the actual URL if this were a real repo).

2.  **Open `index.html`:**
    Navigate to the project directory and simply open the `index.html` file in your preferred web browser. You can usually do this by double-clicking the file.

That's it! The calculator web app will load directly in your browser.

## Usage

-   Click the number buttons (`0-9`, `.`) to input numbers.
-   Click the operator buttons (`+`, `−`, `×`, `÷`) to choose an operation.
-   Click the `=` button to compute the result.
-   Click `C` to clear the current calculation and reset the calculator.
-   Click `DEL` to delete the last entered digit.
-   Use your keyboard for input: `0-9`, `.`, `+`, `-`, `*` (for ×), `/` (for ÷), `Enter` or `=` (for equals), `Backspace` (for DEL), `Escape` or `C` (for clear).

## Design Philosophy

The design aims for clarity and efficiency. A minimalist color palette, subtle shadows, and carefully chosen typography create a sophisticated yet approachable interface. The layout utilizes CSS Grid for the calculator keypad, ensuring perfect alignment and easy responsiveness. Hover and active states provide visual feedback for user interactions, enhancing the overall experience.
